## 5. New in `e0b5125` (minor): `crates/research-tools/src/investigation_outline_tex.rs:133 (split_multirow_body)`

- What is wrong: The new per-row numbering for align/gather/eqnarray/alignat/flalign splits a row at every top-level `\\\\`. It tracks only \\begin/\\end of NESTED_MATH_ENVS and ignores brace depth: `if nested_depth == 0 && seg[i..].starts_with("\\\\") { cur.push(..); rows.push(std::mem::take(&mut cur)); ...`. A `\\\\` inside a brace group, such as `\\sum_{\\substack{i<j \\\\ k}}` (common in physics) or `\\text{..\\\\..}`, starts a phantom row. - Example: \\begin{align} S = \\sum_{\\substack{i<j \\\\ k}} x_i \\end{align} \\begin{equation} E=mc^2 \\end{equation} gives labels 1, 2 for the align and 3 for E=mc^2 (TeX numbers them 1 and 2), so 'eq. (2)' resolves to the phantom half-row.
- To do: Track brace depth (skip `\\{`/`\\}`) in split_multirow_body and split only at depth 0 outside nested envs. Add a test with \\substack inside align followed by an equation.
