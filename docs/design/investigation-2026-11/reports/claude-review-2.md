- What to do: When merged.len() > n_max, merge the closest adjacent ranges (smallest gap first) until at most n_max remain, or group consecutive ranges into n_max slices. Then the slice count always stays ≤ n_max (and ≤ 8). Add a plan test with more disjoint ranges than n_max.

## P16 (minor): `bf0a640 (with ad18a95)`, F6 + F4: a split subequations block in the closer's trailing text silently drops its first equation

- Where: `crates/desktop-server/assets/math_scan.js:341 with crates/desktop-server/assets/markdown.js:444`
- What is wrong: bf0a640 made findEnvBlockClose change its `lines` argument in place when it splits a subequations block: `lines.splice(startLine, l - startLine + 1, '', ...split.tailLines); return { body: split.firstBody, closeLine: startLine, rest: '' };`. The first equation exists only in the returned `body`. ad18a95's F4 fix calls matchBlockDisplay only as a yes/no check and throws the result away: `if (matchBlockDisplay(lines, disp.closeLine)) { i = disp.closeLine - 1; }`. The loop then dispatches again at that line, which the splice has already turned into ''. The first equation is gone, with no error and no visible source left behind.
- Example: markdownToRenderedHtml('$$\nx\n$$\\begin{subequations}\\begin{equation}a=1\\end{equation}\\begin{equation}b=2\\end{equation}\\end{subequations}'). Node output on fixed: data-tex is ["x", "\\begin{equation}b=2\\end{equation}"]. a=1 is not rendered at all. On merged both equations were rendered (as one display). The input is rare: it needs a $$ closer followed on the same line by a subequations block with at least two equations.
- What to do: Keep the block matchers free of side effects. Either have findEnvBlockClose return `tailLines` and let renderMarkdownBlocks splice only when it uses the match, or make the F4 check non-mutating, as the review's fix-risk note suggests: test only whether `tail` starts with $$, \[ or \begin{<math env>}, or run matchBlockDisplay on `lines.slice()`.

- What to do: Optional: after unwrapping, also drop group braces that are not escaped, or leave it as it is.
