## Verification and workflow fixes

- A verifier response that pairs acceptance with an error, blocker, or counterexample is treated as unverified. Saved reviews with contradictory findings show the conflict in the workbench.
- A previous verdict cannot approve a changed proof or a later turn. Computation evidence must have been recorded before the proof entry that cites it.
- The workbench distinguishes full-solution reviews from separate step checks and shows when the Strategist was consulted.
- Antigravity starts in Default mode with the current CLI. Timed-out and incomplete turns no longer appear successful, and user stops remain marked as stopped.
- Exported research bundles can replay calculations with the bundled Windows Python runtime.

Download the installer for Windows 11 x64, close reSearch if it is running, and run setup. Existing research sessions and settings are preserved. Open **reSearch** from Start after installation. [Download the Windows installer](https://github.com/antimajorana/reSearch/releases/download/v0.1.3/reSearch-Setup-Windows-x64.exe)

The installer is unsigned. Its checksum is in `SHA256SUMS.txt`, included with the release.
