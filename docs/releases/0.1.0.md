Download [reSearch-Setup-Windows-x64.exe](https://github.com/antimajorana/re-search/releases/download/v0.1.0/reSearch-Setup-Windows-x64.exe), run the installer on a 64-bit Windows 11 PC, and open **reSearch** from Start.

Setup installs the app for your Windows account and includes Python, SymPy, NumPy, and mpmath for calculations. You can create a project, attach a paper, and inspect sources immediately. Choose **Connect model** to run an AI-assisted research session. The desktop window uses Microsoft Edge WebView2. If your PC is missing the runtime, install the [Evergreen WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

The installer is unsigned. Download it from this release and use the accompanying `SHA256SUMS.txt` to verify the file.

### In this release

- Keep a research question, conventions, findings, and bibliography together across sessions. Drafts and staged attachments stay with their session.
- Open the exact lines cited from an ingested paper, look up declarations in an attached Physlib workspace, and type-check proofs with a configured Lean 4 installation.
- Check symbolic identities and numerical convergence, freeze validation criteria, and compare approaches against a recorded baseline.
- Export a report with its bibliography, recorded evidence, checksums, and replay instructions.
