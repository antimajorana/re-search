The round reSearch icon now appears in the workbench header when the sessions sidebar is closed. Browser tabs and home-screen bookmarks use a higher-resolution copy of the same artwork as the Windows app.

Download the installer for Windows 11 x64, close reSearch if it is running, and run setup. Existing research sessions and settings are preserved. Open **reSearch** from Start after installation. [Download the Windows installer](https://github.com/antimajorana/re-search/releases/download/v0.1.2/reSearch-Setup-Windows-x64.exe)

The installer is unsigned. The accompanying `SHA256SUMS.txt` contains its checksum.
